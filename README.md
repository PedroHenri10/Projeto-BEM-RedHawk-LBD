# API aplicativo cartão BEM em Node JS

aplicativo denominado BEM (Bilhete Eletrônico Municipal), voltado para a modernização e digitalização da gestão de cartões de transporte público. Considerando as dificuldades enfrentadas por usuários no acesso a informações básicas, como saldo e histórico de uso, o projeto visa criar uma solução prática, acessível e segura para passageiros e empresas. O aplicativo oferece funcionalidades como gerenciamento de cartões, recargas digitais, consulta de saldo e histórico. Dessa forma, o sistema proposto pretende otimizar o uso do transporte público e promover maior autonomia aos usuários.
